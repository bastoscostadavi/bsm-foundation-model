BSM Foundation Model explores training a foundation model to infer probability distributions over theories beyond the Standard Model (BSM) and their parameters from experimental data.

We use entries from [bsm-atlas](https://github.com/bastoscostadavi/bsm-atlas) to generate diverse simulation data across theories, parameters, and experimental settings. Supervised learning turns this into a classification task: the model learns to associate unstructured simulation data with its underlying gauge algebra and matter representation. The goal is to learn patterns across many simulated settings and use them to interpret real experimental observations.

The project complements [bsm-ai-search](https://github.com/bastoscostadavi/bsm-ai-search), which uses AI to derive predictions and investigate the consequences of given theories.
