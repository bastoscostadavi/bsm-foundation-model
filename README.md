BSM Foundation Model explores training a foundation model to infer probability distributions over theories beyond the Standard Model (BSM) and their parameters from experimental data. The idea is to generate simulated datasets from candidate theories, train neural networks to infer the underlying physics, and apply the resulting system to real experimental observations. It complements [bsm-atlas](https://github.com/bastoscostadavi/bsm-atlas), which organizes BSM theories, within the broader [bsm-ai-search](https://github.com/bastoscostadavi/bsm-ai-search) project to explore the space of BSM models at scale using AI.
